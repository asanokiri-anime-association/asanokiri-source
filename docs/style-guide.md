# 视觉与样式维护

## 雾境书院

网站像一本属于社团的幻想旅行手记：浅色是暖纸与铜金，深色是墨绿与月白，配以宋体标题、细线边框、魔法观测纹章和学院风景。幻想内容只用于视觉氛围，社团事实与历史照片保持明确的资料来源。

## 从哪里修改

| 目标                                         | 文件                         |
| -------------------------------------------- | ---------------------------- |
| 全站颜色、字体、页宽、页眉高度               | src/styles/theme.css         |
| 文字层级、间距、按钮、链接、Markdown 正文    | src/styles/base.css          |
| 导航、主题按钮、公告、活动列表、二维码与页脚 | src/styles/components.css    |
| 时间轴的舞台、章节、年份导航与响应式布局     | src/styles/chronicle.css     |
| 首页和各内页的栏目排版                       | src/styles/pages.css         |
| 魔法纹章的线条与形状                         | src/components/MagicSeal.vue |
| 首页风景插画                                 | public/art/mist-academy.png  |

每个样式文件按对应页面的阅读顺序排列，响应式覆盖放在末尾。选择器使用有归属的语义类名；仅全局基础元素使用标签选择器。Vue 内不放静态样式，章节数量和进度这类状态通过 CSS 变量或动态属性传递。

## 色彩与字体

常用变量：--page 为页面底色，--ink 为主要文字，--muted 为正文次级色，--gold 为线饰和标签，--line 为分隔线，--night 为深色展示区。

调整浅色、深色时同时检查文字、图片说明、按钮和二维码。主题初始背景同时出现在 theme.css、src/theme/bootstrap.ts 和 index.html；主题色测试需一起更新。

中文标题为 Noto Serif SC Variable，西文字标和年份为 Cormorant Garamond，正文使用系统无衬线字体。字体自行托管，中文字体按 Unicode 范围分片加载，不依赖 Google Fonts 网络。许可见 public/licenses。

## 图标与图片

交互图标从 @lucide/vue 按需导入，通常 18px、1.5px 线宽，并附 aria-hidden；对应链接或按钮仍有文字名称。不要用箭头字符、emoji 或字形模拟按钮图标。

MagicSeal 是装饰 SVG，不传达必要内容，不加入读屏顺序。新增纹章保持类似线宽和留白，避免在主要文字下方叠加高对比纹理。

首页学院风景是独立装饰资源，见 visual-assets.md。CMS 的“首页社团插画”用于文化展示区域，属于真实社团内容，带说明或署名。

## 响应式与动态

标准桌面、平板与手机均保持相同的 DOM 阅读顺序，不使用 order 或反向 flex 重排。

允许动画时，时间轴在所有宽度保持固定。较窄或较低的视口使用横向年份导航，手机将文字和配图上下排列。年份可点击，页面滚动保持原生行为；减少动态效果模式显示全部条目。超出可用高度的章节可在内部滚动阅读。新增历程后检查最长说明与最多年份按钮是否仍适合舞台。

主题切换使用交叉渐变，无支持时退回颜色过渡。减少动态效果时停用过渡。不要用持续闪烁、强制滚动或自动旋转装饰增强“魔法感”。

## 验收

修改后运行类型、构建和现有测试，并用浏览器检查：

- 浅色、深色、跟随系统；刷新时无错误底色。
- 1365×900 的完整桌面布局、978×900 的窄屏布局，以及 390×844、320×568 和 844×390 的手机竖屏与横屏内容。
- 时间轴进入、换章、离开及年份按钮；低高度视口完整阅读。
- 长部门名称、长说明、空栏目与历史照片。
- 键盘焦点、图片说明、手机横向溢出。
